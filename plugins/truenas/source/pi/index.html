All TrueNAS keys use this connection. You only need one Setup key; it shows whether the NAS is connected, and pressing it opens the TrueNAS web page.
How do I get an API key?
  1. Open the TrueNAS web page and sign in.
  2. Click your user icon (top right) and choose My API Keys.
  3. Click Add, give it a name such as "Stream Dock", and save.
  4. Copy the key and paste it above. TrueNAS only shows it once.

Starting and stopping apps needs a key for an admin user. A read-only admin key works for everything else.
