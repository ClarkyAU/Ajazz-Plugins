Soundpad "right sound" patch 1.0.0

Fixes the Soundpad plugin from the Ajazz store playing the wrong sound after you add,
remove or sort sounds in Soundpad.

Install
  1. Install "Soundpad Integration" from the Ajazz store first (if it isn't already).
  2. Unzip this whole zip, then double-click install.bat.
     It closes the Stream Dock software, adds the patch and starts the software again
     (about 10 seconds). Your keys and settings are kept.
  3. Press a Soundpad key: it plays the right sound.

If the Ajazz store updates the Soundpad plugin, run install.bat again.
To remove the patch, double-click uninstall.bat.
