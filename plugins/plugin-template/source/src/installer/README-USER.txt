__NAME__ for Ajazz Stream Dock

INSTALL
1. Unzip this whole folder.
2. Double-click install.bat and answer Y.
3. Restart the Stream Dock software: tray icon, Quit, then open it again.
4. In the software, drag the "__NAME__" keys onto your deck. Add the Setup key first.

UNINSTALL
Double-click uninstall.bat. Your saved settings and readings stay in the plugin's data folder.
