LibreHardwareMonitor

Checking…
Free and open source. Install downloads it from its official GitHub page into Program Files, sets it up to share readings the way chosen above, starts it with Windows (minimised to the tray) and installs PawnIO, the small signed driver it uses to read the CPU. Windows asks for permission once.
Already using LibreHardwareMonitor?

Install it with the button above to keep things simple, or set it up yourself:

  1. Web server: in LibreHardwareMonitor open Options › Remote Web Server, tick Run, and make sure the port matches the one above.
  2. Log file: tick Options › Log Sensors and set the logging interval to 2 seconds. The plugin looks for the log in Program Files\LibreHardwareMonitor.

HWiNFO

Checking…
Start HWiNFO with Sensors-only ticked, open its Settings and tick Shared Memory Support. The free version switches this off after 12 hours until HWiNFO is restarted.

Built-in only

No extra apps. Graphics card readings still come from the NVIDIA or AMD driver. CPU temperature is only available where the AMD driver or Windows reports it (usually laptops and Ryzen chips with built-in graphics).

CPU temperature, fans and other sensors

Windows does not share CPU temperatures with apps on its own. If one of these free apps is running, this plugin reads from it automatically:

  • HWiNFO — in its Settings, tick Shared Memory Support. (The free version turns this off after 12 hours; restart HWiNFO to continue.)
  • LibreHardwareMonitor — just leave it running (start it as administrator so it can read the CPU).

Graphics card temperatures do not need either app: they come from the NVIDIA or AMD driver, or from Windows for other cards.

Choose and set up the app on the Setup key.
